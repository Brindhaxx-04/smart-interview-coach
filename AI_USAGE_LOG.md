# AI Usage Log — Smart Interview Coach

## Project Overview

Smart Interview Coach is a web-based interview practice application that helps users prepare for common interview questions. Users can answer questions and receive structured feedback based on their responses.

## AI-Assisted Development

AI tools were used during development to support:

* Project planning and feature breakdown
* Backend API structure using FastAPI
* Frontend HTML, CSS, and JavaScript development
* Debugging Python and FastAPI errors
* Improving the interview evaluation logic
* Improving the user interface and responsive design
* Git and GitHub workflow guidance
* Testing and troubleshooting the application

## Key Prompts Used

### Project Planning

"Help me build a beginner-friendly Smart Interview Coach project with a FastAPI backend and frontend."

### Backend Development

"Create FastAPI endpoints for interview questions, answer submission, and answer evaluation."

### Debugging

"Help me debug the FastAPI import and routing errors in my project."

### Evaluation

"Create an interview answer evaluation system that provides a score, strengths, suggestions, and feedback."

## Human Contribution

The project was developed and tested by the team during the hackathon. The team reviewed, modified, integrated, tested, and validated the AI-assisted code and decided which features were appropriate for the final project.

## Development Process

The project was developed incrementally during the hackathon. Changes were tested locally and committed to the GitHub repository throughout development.
