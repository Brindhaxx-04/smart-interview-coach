# PROMPTS.md

## AI-Assisted Development Log

This project was developed with AI assistance during the hackathon. AI was used to support planning, debugging, implementation, deployment, and documentation.

### Prompt 1 — Project Planning

I need to build an AI Interview Agent that conducts a technical interview based on a candidate's learning journey. Help me plan a simple architecture for a beginner-friendly implementation using a FastAPI backend and a web frontend.

### Prompt 2 — Interview Flow

Help me design a multi-question interview flow where the candidate answers questions one by one and receives feedback on their responses.

### Prompt 3 — Backend API

Help me create FastAPI endpoints for:
- Getting interview questions
- Submitting an answer
- Evaluating an answer

The API should return structured JSON responses.

### Prompt 4 — Answer Evaluation

Help me implement a simple answer evaluation system that considers the candidate's response length and provides:
- Score
- Strengths
- Suggestions
- Feedback

### Prompt 5 — Frontend Integration

Help me connect the frontend JavaScript to the FastAPI backend so that questions, answers, evaluation results, and the interview flow work together.

### Prompt 6 — Interview Completion

Help me implement an interview completion screen after the candidate finishes all 10 questions instead of restarting from the first question.

### Prompt 7 — Debugging

Help me debug FastAPI syntax and deployment errors and identify why the application was not starting correctly.

### Prompt 8 — Deployment

Help me prepare the FastAPI application for cloud deployment and troubleshoot deployment errors.

### Prompt 9 — Final Testing

Help me test the complete interview flow from the first question through the final question and verify that the completion screen appears correctly.

## AI Usage

AI assistance was used as a development support tool. The final project was tested, modified, and deployed by the team.
